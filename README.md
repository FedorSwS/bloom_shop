# Bloom Shop — Интернет-магазин цветов и букетов (г. Тула)

Полнофункциональный интернет-магазин цветов с каталогом из **36 готовых букетов** (включая 8 свадебных композиций), каталогом **24 сортов свежих цветов поштучно**, конструктором **«Соберите композицию мечты»** (все 24 сорта с фото), выбором упаковки (**Без упаковки 0 ₽** + 10 вариантов оформления), **12 сопутствующими товарами с фото**, личным кабинетом, корзиной, центром уведомлений, записью к шеф-флористу, интерактивной **Яндекс.Картой** 3 салонов в Туле и локальным/облачным бэкендом.

## Локальный запуск

Требуется установленный **Node.js 18+**.

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального REST API сервера (http://localhost:3001)
npm run server

# 3. В отдельном терминале — запуск фронтенда (http://localhost:8443)
npm run dev
```

Проверка работоспособности API: `http://localhost:3001/api/health`.
Все заказы, корзины, профили, бонусы и заявки шеф-флористу сохраняются в `server/db.json`.

## Сборка для продакшена (Netlify / хостинг)

```bash
npm run build
```
